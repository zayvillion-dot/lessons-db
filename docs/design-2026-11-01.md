# Design: lessons-db (2026-11-01)

## Origin

A house rule since October 2026: after a reboot wiped a whole review round's reports, every round's ledger entries and review files are committed to the repo at round close. Only the committed ledger had survived. The skill generalizes the rule so any agent keeps review memory the same way.

## Form

Shaping plus discipline. Without the skill, agents keep review output in chat, summarise defects without root cause or rule, and never consult prior lessons. So the skill is a recipe for the entry and section shapes, plus a short rationalization table for "we'll remember", "I'll write it at the end", and "the scratchpad is fine".

## Recipe rationale

- One row per defect, with root cause and an imperative prevention rule, so a lesson can be applied, not just recalled.
- A section per review with counts and status shows how a review ended, including refuted findings.
- Round files in `docs/reviews/` keep the evidence next to the code, committed with the ledger.
- Append-only keeps history trustworthy.
- Reading the rules before similar work is the payoff; without it the ledger is an archive.
